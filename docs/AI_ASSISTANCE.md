# AI Assistance

This repository is an AI-assisted engineering project.

The user specified the career objective, product direction, scope boundaries, deadline/freeze policy, safety permissions, non-goals, and detailed acceptance criteria. Codex GPT-5.6 Sol refined the architecture and produced the implementation, tests, debugging work, binary protocol, deterministic transport, replay/report/desync tooling, real UDP/process path, interactive viewer, documentation, evidence, and packaging in this work session.

The user did not hand-write the delivered code during this session. The project must not be described as independently hand-written by the user, and its AI involvement must not be hidden in a résumé, portfolio, interview, or repository history.

Before presenting it in an interview, the user should personally complete at least one exercise from [LIVE_CHANGE_DRILLS.md](LIVE_CHANGE_DRILLS.md) and be able to explain prediction, snapshot boundaries, earliest-dirty rollback, confirmed frames, packet redundancy, replay verification, and desync diagnosis without reading a script.

AI assistance does not make the verification claims self-authenticating. The checked tests, exact commands, artifacts, commits, limitations, and Draft PR evidence are the basis for review.
